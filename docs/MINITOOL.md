# 小红书小工具

以公开版为基础，保留九个地点、风景照片墙、手账、包花、点菜、图书馆、雨后彩虹与自由庆祝。没有私人信件、人物图像或户外第一人称模式。

## 构建

```sh
npm ci
npm run build:minitool
```

需要官方 `minitool-zip-builder` **1.8.0**。默认从上级工作区的 `.codex/skills/minitool-zip-builder` 读取审计脚本，也可设置 `MINITOOL_SKILL_DIR`。规范在 2026-10-19 与在线文档核对过；在线新增的 AI 文本生成能力不用于本项目。

产物：

- `dist-minitool/`：离线目录，根目录为 `index.html`。
- `release/island-for-you-minitool-v1.0.2.zip`：待上传包。
- 同目录 `.validation.json`：大小、SHA-256、审计状态。

构建独立于网页，不会改动网页入口或发布目录。模型解码与简化只在构建机执行；容器中读取的是普通 JavaScript 几何数组，不使用 WASM、Worker 或联网资源。字体、图片和材质全部随包提供，入口为 ES2017 经典脚本；针对本项目使用的较新 JS/CSS 能力提供局部回退。

## 容器适配

- 天空连续铺到屏幕顶端；控制按钮位于系统安全区和导航高度以下。弹窗、图册和花店在剩余可用高度中布局，横屏与键盘弹出时重新计算。
- 进度优先使用原生 Storage。支持文件 API 的客户端将拍照原图保存在小工具自己的持久目录；旧客户端使用受大小限制的本地存储回退。相册保留多次拍照记录，读取缓存最多六张。
- 保存到手机使用 `saveImageToPhotosAlbum`，发笔记使用 `postNote` 打开编辑页。失败时保留照片并允许重试；不会自动发布笔记。
- 离线包不包含网页的五首商业录音。五段原创合成旋律按顺序循环，配有轻量点击音效；退到后台时暂停声音。

## 渲染预算与恢复

默认像素比不超过 1.5、单画布不超过 180 万像素，关闭阴影贴图和全屏后期效果。六组静态模型从 202,927 面减至 64,990 面，材质合并并保留独立的房间开口。花店打开时暂停岛屿画布；后台停止渲染。长时间低帧率降低分辨率，持续无法恢复则切换到可操作的轻盈模式。缺少 WebGL 2、初始化失败或反复丢失上下文时也提供回退；花店仍能以二维预览继续完成花束。

2026-10-19，M2 MacBook Air、本机 Chrome、402 × 874 触摸模拟，23 个场景状态采样为 29,067–98,648 个三角面、7–65 次绘制。全岛视图 89,292 面 / 65 次；十二枝复杂花束最高 98,648 面；四道菜同时上桌 79,110 面 / 39 次；夜间点亮蛋糕 90,652 面 / 27 次。所有采样低于 10 万面，数字仅反映测试中的状态，不代表真机帧率或全部组合的峰值。

## 验证边界

官方目录审计、ZIP 审计及本地禁用能力/语法/路径检查均通过。`scripts/minitool/verify.mjs` 用嵌套路径和严格 CSP 检查 320 × 568、390 × 844、430 × 932、568 × 320 四种尺寸，并模拟原生存储、文件、相册和笔记接口；检查了图库、手账、照片恢复、包花、点菜、图书馆、彩虹、庆祝及图形故障恢复。截图与机器结果保存在忽略提交的 `output/minitool/`。

v1.0.1 增加 `scripts/minitool/verify-layout.mjs`，在 320 × 568、375 × 667、390 × 844、430 × 932、568 × 320、844 × 390 六种尺寸下检查工具栏、退出、倒计时、曲名、场景卡片及按钮的矩形交叠和真实点击命中。覆盖顶部 0/20/47/59 px、底部 0/20/21/34 px 的安全区，以及键盘可视高度变化、四道菜、点菜反馈和拍照。v1.0.2 的 83 项本地布局／交互检查通过（绿光不再要求点击）；普通浏览器不能验证真实系统键盘或容器 API。

v1.0.2 增加 `scripts/minitool/verify-details.mjs`，检查 23 个场景状态和绘制预算，截图近看花束、伞柄、旋转木马、蜡烛与火焰，覆盖从日出入口沿路上山及夜间点燃／吹灭。结果在 `output/minitool-details-v102/`；无浏览器运行错误。

使用 develop-web-game 客户端完成输入回放，检查点燃到吹灭蜡烛的画面与状态；该工具的时间推进模式不用于评估真实帧率。两个网页版本的日出镜头和绿光自动记录也完成回归。

**普通浏览器近似检查不能作为小工具容器验收。** 本次尚未在创服平台和物理手机上运行。上传同一 ZIP 后，需依次完成：
