# 小红书小工具

以公开版为基础，保留九个地点、风景照片墙、手账、包花、点菜、图书馆、雨后彩虹与自由庆祝。没有私人信件、人物图像或户外第一人称模式。

## 构建

```sh
npm ci
npm run build:minitool
```

需要官方 `minitool-zip-builder` **1.8.0**。默认从上级工作区的 `.codex/skills/minitool-zip-builder` 读取审计脚本，也可设置 `MINITOOL_SKILL_DIR`。规范在 2026-10-18 与在线文档核对过；在线新增的 AI 文本生成能力不用于本项目。

产物：

- `dist-minitool/`：离线目录，根目录为 `index.html`。
- `release/island-for-you-minitool-v1.0.0.zip`：待上传包。
- 同目录 `.validation.json`：大小、SHA-256、审计状态。

构建独立于网页，不会改动网页入口或发布目录。模型解码与简化只在构建机执行；容器中读取的是普通 JavaScript 几何数组，不使用 WASM、Worker 或联网资源。字体、图片和材质全部随包提供，入口为 ES2017 经典脚本；针对本项目使用的较新 JS/CSS 能力提供局部回退。

## 容器适配

- 天空连续铺到屏幕顶端；控制按钮位于系统安全区和导航高度以下。弹窗、图册和花店在剩余可用高度中布局，横屏与键盘弹出时重新计算。
- 进度优先使用原生 Storage。支持文件 API 的客户端将拍照原图保存在小工具自己的持久目录；旧客户端使用受大小限制的本地存储回退。相册保留多次拍照记录，读取缓存最多六张。
- 保存到手机使用 `saveImageToPhotosAlbum`，发笔记使用 `postNote` 打开编辑页。失败时保留照片并允许重试；不会自动发布笔记。
- 离线包不包含网页的五首商业录音。五段原创合成旋律按顺序循环，配有轻量点击音效；退到后台时暂停声音。

## 渲染预算与恢复

默认像素比不超过 1.5、单画布不超过 180 万像素，关闭阴影贴图和全屏后期效果。六组模型从约 24.3 万面减至约 5.7 万面，材质合并并保留独立的房间开口。花店打开时暂停岛屿画布；后台停止渲染。长时间低帧率降低分辨率，持续无法恢复则切换到可操作的轻盈模式。缺少 WebGL 2、初始化失败或反复丢失上下文时也提供回退；花店仍能以二维预览继续完成花束。

2026-10-18，M2 MacBook Air、本机 Chrome、390 × 844 触摸模拟中，全岛视图约 67–75 次绘制、7.5 万三角面；食堂约 23 次 / 5.4 万面，庆祝约 37 次 / 7 万面。十二枝复杂花束约 28 次 / 9.54 万面。数字反映这些采样状态，不代表真机帧率或全部场景的峰值。

## 验证边界

官方目录审计、ZIP 审计及本地禁用能力/语法/路径检查均通过。`scripts/minitool/verify.mjs` 用嵌套路径和严格 CSP 检查 320 × 568、390 × 844、430 × 932、568 × 320 四种尺寸，并模拟原生存储、文件、相册和笔记接口；检查了图库、手账、照片恢复、包花、点菜、图书馆、彩虹、庆祝及图形故障恢复。截图与机器结果保存在忽略提交的 `output/minitool/`。

**普通浏览器近似检查不能作为小工具容器验收。** 本次尚未在创服平台和物理手机上运行。上传同一 ZIP 后，需依次完成：

1. 创服平台模拟器的完整流程。
2. Android 真机扫码，重点查看音频解锁、拖动、键盘、安全区、保存相册及低性能恢复。
3. iOS 真机扫码，重复同一流程。

Android 8.1 / Chrome 61 的实际运行也仍待验证；编译目标与静态检查不能替代实机结果。
