# Fonts

All four are under the SIL Open Font License 1.1 and self-hosted as subsets of the interface characters
(`scripts/prepare_fonts.py`). Other text falls back to the device's installed system fonts.

- Noto Serif SC — Google / Adobe, `island-serif.woff2`. https://github.com/notofonts/noto-cjk · `OFL-NotoSerifSC.txt`
- Long Cang — The Long Cang Project Authors, `island-hand.woff2` (the journal's handwriting). https://github.com/googlefonts/longcang · `OFL-LongCang.txt`
- LXGW WenKai (霞鹜文楷) — LXGW, `island-hand-body.woff2` (the journal's sentences), subset for web delivery only as its license allows. https://github.com/lxgw/LxgwWenKai · `OFL-LXGWWenKai.txt`
- Caveat — The Caveat Project Authors, `island-hand-latin.woff2` (the journal's dates and numbers). https://github.com/googlefonts/caveat · `OFL-Caveat.txt`
